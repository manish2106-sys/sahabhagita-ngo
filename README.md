# Sahabhagita NGO Website

Official website for **Sahabhagita Shahri & Gramin Vikas Samiti** — empowering underserved communities through practical education, sustainable livelihoods, and hands-on technology since 2004.

## Features
- Responsive single-page website
- Donation & Contact forms with full validation
- Security hardened (CSP, XSS protection, rate limiting, honeypot anti-spam)
- Accessible (WCAG 2.1 compliant)
- SEO optimized with Open Graph

## Security
- Content Security Policy (CSP) headers
- XSS protection with input sanitization
- No inline JavaScript (CSP-safe)
- Rate limiting on form submissions
- Honeypot anti-spam fields
- Input validation (email, phone, PAN)
- Script injection pattern detection
